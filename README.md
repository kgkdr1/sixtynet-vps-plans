## 独立 IP、原生 IP、住宅 IP、双 ISP，四个词各管什么

独立 IP 说的是归属关系：这台机器独占一个 IPv4，不跟别人共用同一个出口。共享 IP 的风险是同段其他人被搜索引擎或平台拉黑时你跟着受牵连，做多店铺、多账号的怕的就是这种连坐。

原生 IP 说的是注册归属：这个段在 ARIN 登记，WHOIS 查出来是美国本土运营商，而不是别国 IDC 广播过去的段。归属判定准确，Netflix、ChatGPT 这类看 IP 归属的服务通过率会高一些。

住宅 IP 说的是段的性质：它属于民用宽带运营商，不是 Hosting 段。平台风控给住宅段的信任度普遍高于机房段，这是它溢价的来源。

双 ISP 是数据库层面的事：ipinfo 这类库里，这个 IP 同时归属两家运营商，真实家庭宽带常见这种结构。SixtyNet 官网只写了“Residential IP”，没展开单 ISP 还是双 ISP；第三方测评用 ipinfo 查出来是双 ISP 属性，上游是 Cox Communications。这条信息对判断有用，但它来自测评，不是官网承诺。

自己验一遍并不难，下单后十分钟能做完：

1. 把 IP 丢进 ipinfo.io，看 org 和 ASN 是运营商还是 hosting 商。
2. 用 whois 查注册机构和所属国家。
3. 查 Spamhaus、CleanTalk 这类黑名单库，看这个段有没有历史记录。

三步都过了，IP 这一项才算合格。做完不满意，才是轮到退款政策出场的时候。

## 2G、10G 写的是端口，不是你能跑满的速度

官网把网络写成“2G Premium Network”“10G Premium Network”，指的是端口速率。VPS 的端口速率一般是共享上限，同一台物理机上的人分这条口子，标称 10G 不等于你随时能跑出 10G。

按业务看就更清楚。传大文件、跑备份、做图床，看的是月流量额度和端口上限，Residential-LARGE 的 40TB 才是它的卖点。跑账号、看视频、做验证，5TB 能用很久，端口给多大都不是瓶颈。

线路方面，第三方测评给出的路由是：电信去程 CN2 直连洛杉矶，联通去程直连后接 GTT 再接 Cox，移动去程直连；回程电信和移动走 CN2，联通走 AS10099 加 AS9929。这是测评当次测出来的结果，官网没有对路由作出承诺，你手上那台走哪条路径，以自己 traceroute 的结果为准。同一篇测评还提到官方屏蔽了 PING，所以别拿 ping 判断延迟，用 tcping 打端口更靠谱。

硬件上，测评显示是 AMD EPYC 7002 系列加 NVMe，两篇不同时期的测评给出的 I/O 分别是 188MB/s 和 98MB/s，测评作者自己也认为偏弱。跑网站、跑账号没问题，拿它跑数据库密集型的活会难受。
